# Impulse

Aplicación personal de hábitos, objetivos, progreso, finanzas, alimentación, ejercicio, vicios e IA.

## GitHub Pages

Este proyecto está preparado para GitHub Pages en un repositorio con URL tipo `/impulseprueba/`. El deploy se realiza automáticamente con `.github/workflows/deploy.yml`.

## Desarrollo

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

## Supabase

Configurar `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY` en el entorno de build.
